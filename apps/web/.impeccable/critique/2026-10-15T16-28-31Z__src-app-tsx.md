## What's Working

- Formula and named learning action make purpose clear.
- Coherent light/dark themes and labeled bottom navigation.
- Encouraging, explanatory grading: expected answer, explanation and rule.

## Priority Issues

1. **P1: Disconnected QCM controls.** Desktop/390px radios are oversized and
   centered with labels below at the left. Generic input and label CSS causes
   this. Use compact native radio inside a full clickable row, adjacent label
   and separate validation action. Suggested command: impeccable polish.
2. **P2: Musical content interrupted.** At 320px the last half-tone wraps alone;
   catalog cards at 390px show only six complete notes. Keep formula groups
   together and let static notes wrap; do not change interactive piano behavior.
   Suggested command: impeccable adapt.
3. **P2: Active exercise type hidden.** Horizontal choices put selected interval
   exercise outside narrow viewport. Use one clearly labeled selection control.
   Suggested command: impeccable adapt.
4. **P2: Incorrect QCM help.** Note-separator instructions appear when users must
   choose tone/half-tone. Show text-entry guidance only for text responses.
   Suggested command: impeccable clarify.
5. **P2: Progress has no clear continuation.** Four stacked statistics fill 320px
   screen, singular counts use plural labels, and initial state has no in-content
   next action. Keep compact stats, grammatical counts and a continuation action.
   Suggested command: impeccable polish.

QCM guidance conflicts with the control. Phone user: hidden types and truncated
notes. Screen-reader user: contextual control names and focus deserve attention.

focus and contextualize catalog details links. Secondary routes retain global
navigation but have no selected top-level nav item.
